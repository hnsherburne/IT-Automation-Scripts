
# PowerShell Scripts

PowerShell automation tools for IT administration,
security auditing, and endpoint management. Cleaned up and modernized with proper comments and format with the assistance of AI.

## Categories

- Windows administration
- Microsoft 365 and Entra ID reporting
- Intune and device management
- Security configuration auditing
- System inventory and troubleshooting

## Usage

Review each script before execution.
Check prerequisites and required permissions.
Test in a non-production environment first.

## Security

Never commit passwords, access tokens, private keys,
production data, or confidential company information.
