# Bash Scripts

Bash automation tools for system administration,
security auditing, endpoint management, and troubleshooting. Cleaned up and modernized with proper comments and format with the assistance of AI.

## Categories

* Linux and macOS administration
* System configuration and maintenance
* Security configuration auditing
* System inventory and diagnostics
* File and process management
* Networking and connectivity troubleshooting
* Automation and deployment

## Usage

Review each script before execution.
Check prerequisites and required permissions.
Test in a non-production environment first.

## Security

Never commit passwords, access tokens, private keys,
production data, or confidential company information.
